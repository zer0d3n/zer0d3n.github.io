I'm learning cloud security from scratch while I work. I follow
[Learn to Cloud](https://learntocloud.guide) with AWS as my main cloud and a clear goal: being able to assess,
defend and certify other people's AWS accounts.

This blog is my public notebook. Every week I write down **what I did, what I learned and where I got stuck**,
with no polish: what works, what doesn't, and how I solved it.

## What you'll find here

- **Foundations:** Linux, Bash, networking and Git, with a security mindset.
- **Cloud:** AWS, Terraform, containers and CI/CD with security built in.
- **Security:** least-privilege IAM, detection, incident response and hands-on labs (flaws.cloud, CloudGoat, Pwned Labs).
- **Certifications:** AWS Cloud Practitioner and AWS Security Specialty, with what helped and what didn't.

I never publish challenge solutions or data from my accounts: I share the method, not the answer.

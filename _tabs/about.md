Estoy aprendiendo seguridad cloud desde cero mientras trabajo. Sigo [Learn to Cloud](https://learntocloud.guide)
con AWS como nube principal y un objetivo claro: poder evaluar, defender y certificar cuentas de AWS de otros.

Este blog es mi cuaderno público. Cada semana escribo **qué hice, qué aprendí y dónde me atasqué**, sin adornos:
lo que funciona, lo que no y cómo lo resolví.

## Qué vas a encontrar

- **Fundamentos:** Linux, Bash, redes y Git con mirada de seguridad.
- **Nube:** AWS, Terraform, contenedores y CI/CD con seguridad integrada.
- **Seguridad:** IAM de mínimo privilegio, detección, respuesta a incidentes y laboratorios (flaws.cloud, CloudGoat, Pwned Labs).
- **Certificaciones:** AWS Cloud Practitioner y AWS Security Specialty, con lo que me sirvió y lo que no.

Nunca publico soluciones de retos ni datos de mis cuentas: cuento el método, no la respuesta.
